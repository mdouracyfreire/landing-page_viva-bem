A **Viva Bem** é uma página institucional desenvolvida como desafio prático do **Bootcamp VaiNaWeb Fullstack**. Este projeto foi desenvolvido com foco na criação de uma **Landing responsiva e funcional**, aplicando boas práticas de HTML, CSS e SCSS, além de organização semântica e estrutura moderna de layout.

O objetivo principal foi **praticar e aplicar conceitos de desenvolvimento web moderno**, com foco em:

✅ Estrutura semântica com HTML5  
✅ Estilização avançada com SCSS (variáveis, mixins, organização modular)  
✅ Construção de layout responsivo  
✅ Boas práticas de design, espaçamento, hierarquia e tipografia  
✅ Deploy profissional com Vercel  

🔗 **Acesse o projeto online:**  
https://landing-page-viva-bem.vercel.app/

## 🧭 Seções da Landing Page

✔️ **Banner Inicial**  
Apresentação do tema com destaque visual, título chamativo em **gradiente**, botões de ação e estrutura responsiva.

✔️ **Exames por Faixa Etária e Gênero**  
Cards informativos com exames recomendados para **público masculino e feminino**, organizados visualmente com cores temáticas.

✔️ **Alertas Importantes**  
Quadros com mensagens de atenção, cada um com paleta de cor representativa para facilitar a identificação.

✔️ **Rodapé**  
Informações adicionais, links úteis, frase de impacto e créditos do projeto.

## 📱 Responsividade

O layout foi planejado para ser responsivo, com ajustes para diferentes resoluções:

```scss
@media (max-width: 840px) { ... }
@media (max-width: 576px) { ... }
```

🔹 Redução de fontes e espaçamentos  
🔹 Centralização de elementos  
🔹 Ajuste automático de cards (flex-wrap)  
🔹 Botões e navegação otimizados para toque

## 🧰 Como Executar Localmente

**🔹 1. Clonar o repositório**
```bash
git clone https://github.com/mdouracyfreire/landing-page_viva-bem.git
```
**🔹 2. Entrar na pasta do projeto**
```bash
cd landing-page_viva-bem
```
**🔹 3. Abra o arquivo index.html diretamente no navegador ou utilize a extensão Live Server do VS Code**
